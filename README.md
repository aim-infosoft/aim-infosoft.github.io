## 🚀 Local Development

To run this site locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/aim-infosoft/aim-infosoft.github.io.git
   ```

2. Open `index.html` in your web browser, or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (with npx)
   npx serve
   ```

3. Visit `http://localhost:8000` in your browser

## 🎨 Customization

### Updating Colors

Edit the CSS variables in `assets/css/style.css`:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    /* ... other colors */
}
```

### Updating Content

Edit `index.html` to update:
- Company information
- Services offered
- Contact details
- Statistics

### Adding Images

Place images in the `assets/images/` directory and reference them in your HTML.
